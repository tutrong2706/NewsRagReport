\section{News RAG Pipeline on AWS ---
Workshop}}

\hypertarget{giux1edbi-thiux1ec7u-dux1ef1-uxe1n}{%
\subsection{Giới thiệu dự án}}

\textbf{News RAG Pipeline on AWS} là hệ thống end-to-end hoàn chỉnh tự
động thu thập tin tức từ các báo điện tử Việt Nam, xử lý qua Data
Warehouse (Star Schema), tạo vector embedding bằng Amazon Bedrock, và
cung cấp giao diện hỏi đáp thông minh sử dụng kiến trúc RAG
(Retrieval-Augmented Generation) --- tất cả chạy serverless trên AWS.

\hypertarget{tux1ed5ng-quan-kiux1ebfn-truxfac}{%
\subsection{Tổng quan kiến
trúc}}

\hypertarget{phuxe1t-triux1ec3n-cux1ee5c-bux1ed9-v1---docker-compose}{%
\subsubsection{Phát triển cục bộ (v1 - Docker
Compose)}}

\begin{verbatim}
Scrapy Crawler $\rightarrow$ Kafka $\rightarrow$ PostgreSQL $\rightarrow$ ETL (Star Schema) $\rightarrow$ SentenceTransformer $\rightarrow$ Qdrant $\rightarrow$ RAG API
\end{verbatim}

\hypertarget{triux1ec3n-khai-production-aws-serverless-v2---hiux1ec7n-tux1ea1i}{%
\subsubsection{Triển khai Production AWS Serverless (v2 - Hiện
tại)}}

\begin{verbatim}
EventBridge Scheduler (01:00, 02:00 UTC)
       |
       |---> Fargate Crawler (SitemapSpider) --> SQS --> Lambda Consumer --> Aurora PostgreSQL
       |
       `---> Lambda ETL + Embedding (Bedrock Titan) --> Aurora pgvector (HNSW Index)
                           |
                           v
                    Lambda RAG API <-- API Gateway <-- Client
                    (Bedrock embed query $\rightarrow$ pgvector search $\rightarrow$ Groq/Gemini LLM)
\end{verbatim}

\hypertarget{mux1ee5c-tiuxeau-hux1ecdc-tux1eadp}{%
\subsection{Mục tiêu học tập}}

Sau khi hoàn thành workshop này, bạn sẽ có thể:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Infrastructure as Code}: Định nghĩa hạ tầng AWS bằng Terraform
  (VPC, Aurora, ECS, Lambda, EventBridge)
\item
  \textbf{Serverless Containers}: Đóng gói và triển khai Scrapy crawler
  trên ECS Fargate với ECR
\item
  \textbf{Thiết kế Data Warehouse}: Triển khai Star Schema trên Aurora
  PostgreSQL với extension pgvector
\item
  \textbf{Tự động hóa luồng công việc}: Lên lịch pipeline hàng ngày bằng
  EventBridge Scheduler
\item
  \textbf{Hệ thống RAG}: Tích hợp vector database (pgvector) với API LLM
  cho hỏi đáp thông minh
\item
  \textbf{Tối ưu chi phí}: Tận dụng dịch vụ serverless để giảm thiểu chi
  phí vận hành (\textasciitilde\$21-26/tháng)
\end{enumerate}

\subsection{Điều kiện tiên

\begin{itemize}
\tightlist
\item
  \textbf{Tài khoản AWS} với quyền cho: VPC, EC2, RDS, ECS, ECR, Lambda,
  SQS, EventBridge, API Gateway, Bedrock, CloudWatch, IAM
\item
  \textbf{AWS CLI} đã cấu hình (\texttt{aws\ configure})
\item
  \textbf{Terraform} \textgreater= 1.5.0
\item
  \textbf{Docker} \& \textbf{Docker Compose}
\item
  \textbf{Python} 3.10+
\item
  \textbf{Git}
\item
  \textbf{API Keys bên ngoài}: Groq API Key, Google Gemini API Key
\item
  \textbf{Truy cập Model Bedrock}: Bật
  \texttt{amazon.titan-embed-text-v2:0} trong AWS Console
\end{itemize}
