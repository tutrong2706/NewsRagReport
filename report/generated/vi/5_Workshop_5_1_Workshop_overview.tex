\section{News RAG Pipeline trên AWS --- Tổng quan
Workshop}}

Workshop này hướng dẫn bạn xây dựng một \textbf{News RAG
(Retrieval-Augmented Generation) Pipeline} hoàn chỉnh trên AWS sử dụng
kiến trúc serverless. Bạn sẽ học cách thiết kế, triển khai và vận hành
một hệ thống end-to-end tự động thu thập tin tức, xử lý thành Data
Warehouse, tạo vector embedding, và cho phép hỏi đáp thông minh bằng LLM
--- tất cả chạy serverless trên AWS.

\hypertarget{mux1ee5c-tiuxeau-hux1ecdc-tux1eadp}{%
\subsection{Mục tiêu học tập}}

Sau khi hoàn thành workshop này, bạn sẽ có thể:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Infrastructure as Code}: Định nghĩa hạ tầng AWS bằng Terraform
  (VPC, Aurora, ECS, Lambda, EventBridge)
\item
  \textbf{Serverless Containers}: Đóng gói và triển khai Scrapy crawler
  trên ECS Fargate với ECR
\item
  \textbf{Thiết kế Data Warehouse}: Triển khai Star Schema trên Aurora
  PostgreSQL với extension pgvector
\item
  \textbf{Tự động hóa Workflow}: Lên lịch pipeline hàng ngày bằng
  EventBridge Scheduler
\item
  \textbf{Hệ thống RAG}: Tích hợp vector database (pgvector) với LLM
  APIs cho hỏi đáp thông minh
\item
  \textbf{Tối ưu chi phí}: Tận dụng dịch vụ serverless để giảm thiểu chi
  phí vận hành (\textasciitilde\$21-26/tháng)
\end{enumerate}

\hypertarget{ux111iux1ec1u-kiux1ec7n-tiuxean-quyux1ebft}{%
\subsection{Điều kiện tiên
quyết}}

\begin{itemize}
\tightlist
\item
  \textbf{Tài khoản AWS} với quyền cho: VPC, EC2, RDS, ECS, ECR, Lambda,
  SQS, EventBridge, API Gateway, Bedrock, CloudWatch, IAM
\item
  \textbf{AWS CLI} đã cấu hình (\texttt{aws\ configure}) với thông tin
  xác thực phù hợp
\item
  \textbf{Terraform} \textgreater= 1.5.0 đã cài đặt
\item
  \textbf{Docker} \& \textbf{Docker Compose} đã cài đặt
\item
  \textbf{Python} 3.10+ với pip
\item
  \textbf{Git} để kiểm soát phiên bản
\item
  \textbf{Trình soạn thảo mã} (VS Code khuyến nghị)
\end{itemize}
