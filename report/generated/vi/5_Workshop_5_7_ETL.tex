\hypertarget{aws-lambda-version-production}{%
\subsection{AWS Lambda Version
(Production)}}

For AWS, ETL runs as \textbf{Lambda function} triggered by EventBridge
(02:00 UTC), using \textbf{Bedrock Titan Embed v2} for embeddings
directly in the same function. See \href{5.12-Lambda-ETL/}{Lambda ETL +
Embedding}.

Key differences: - \textbf{Embedding}: Calls
\texttt{bedrock-runtime.invoke\_model} instead of local
SentenceTransformer - \textbf{Vector DB}: Writes to Aurora
\texttt{fact\_chunks.embedding} (pgvector) instead of Qdrant -
\textbf{Secrets}: Reads DB credentials from AWS Secrets Manager -
\textbf{Timeout}: 15 minutes (processes \textasciitilde50 articles per
invocation)
