\hypertarget{aws-lambda-version-production}{%
\subsection{AWS Lambda Version
(Production)}}

Cho AWS deployment, consumer chạy as Lambda function triggered by SQS
(không phải Kafka trực tiếp). Xem \href{5.11-Lambda-Consumer/}{Lambda
Consumer} cho implementation SQS \(\rightarrow\) Lambda \(\rightarrow\)
Aurora.

Khác biệt chính: - \textbf{Trigger}: SQS queue (không phải Kafka) -
\textbf{Runtime}: Python 3.11 Lambda (15 min timeout) -
\textbf{Database}: Aurora PostgreSQL (không phải local) -
\textbf{Secrets}: Lấy từ AWS Secrets Manager - \textbf{Batching}: Xử lý
up to 10 messages per invocation
