\subsubsection{Kết quả đạt được tuần
7:}}

\begin{itemize}
\item
  Integration test thành công trên full pipeline:

  \begin{itemize}
  \tightlist
  \item
    Crawl \textasciitilde500 bài/lần chạy từ 3 báo
  \item
    ETL xử lý: clean HTML \(\rightarrow\) chunk 800 chars (overlap 150)
    \(\rightarrow\) insert Star Schema
  \item
    Vectorize: embedding bằng \texttt{BAAI/bge-small-en-v1.5}
    \(\rightarrow\) upsert vào Qdrant
  \item
    RAG API: query \(\rightarrow\) embed \(\rightarrow\) search top-k
    \(\rightarrow\) LLM generate answer
  \end{itemize}
\item
  Xử lý edge cases quan trọng:

  \begin{itemize}
  \tightlist
  \item
    \textbf{Author invalid}: Phát hiện và loại bỏ 15+ loại fake author
    (URL, ngày tháng, tên báo, ký tự đặc biệt)
  \item
    \textbf{Date parsing}: Hỗ trợ 3 format (ISO, VN dd/mm/yyyy,
    date-only) + fallback qua 10 CSS selectors
  \item
    \textbf{Empty content}: Skip bài viết có content \textless{} 100 ký
    tự
  \item
    \textbf{ETL author cleanup}: Loại bỏ author dài \textgreater{} 40
    chars, chứa http/\textbar/@
  \end{itemize}
\item
  Kết quả đánh giá Ragas: \textbar{} Chỉ số \textbar{} NewsRAG
  \textbar{} FlashRAG \textbar{}
  \textbar----------------------\textbar----------------\textbar----------------\textbar{}
  \textbar{} \textbf{Context Precision} \textbar{} \textbf{Cao hơn}
  \textbar{} Trung bình \textbar{} \textbar{} \textbf{Context Recall}
  \textbar{} Trung bình \textbar{} \textbf{Cao hơn} \textbar{}
  \textbar{} \textbf{Faithfulness} \textbar{} Trung bình \textbar{}
  \textbf{Cao hơn} \textbar{} \textbar{} \textbf{Answer Relevancy}
  \textbar{} Tương đương \textbar{} Tương đương \textbar{}

  Tổng thể các chỉ số ở mức khiêm tốn (dưới 0.5) do prompt RAG được cấu
  hình trả lời chi tiết, diễn giải đầy đủ \(\rightarrow\) làm giảm
  cosine similarity khi Ragas dịch ngược thành câu hỏi.
  \end{quote}
