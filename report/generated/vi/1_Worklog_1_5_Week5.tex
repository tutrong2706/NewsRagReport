\subsubsection{Kết quả đạt được tuần
5:}}

\begin{itemize}
\item
  Cấu hình SQS thành công:

  \begin{itemize}
  \tightlist
  \item
    \textbf{SQS Standard Queue}: \texttt{newsrag-articles} --- chi phí
    \textasciitilde\$0/tháng (so với Kafka tốn thêm quản lý)
  \item
    \textbf{Dead Letter Queue}: \texttt{newsrag-articles-dlq} --- bắt
    messages bị lỗi sau 3 lần retry
  \item
    Message retention: 4 ngày, visibility timeout: 30 giây
  \end{itemize}
\item
  Hiểu rõ lý do chuyển từ Kafka sang SQS: \textbar{} Tiêu chí \textbar{}
  Kafka (v1) \textbar{} SQS (v2) \textbar{}
  \textbar-----------------\textbar---------------------\textbar------------------------\textbar{}
  \textbar{} Chi phí \textbar{} Tốn container Kafka \textbar{}
  \textasciitilde\$0/tháng \textbar{} \textbar{} Quản lý \textbar{} Phải
  maintain broker \textbar{} Fully managed \textbar{} \textbar{} Use
  case \textbar{} Real-time streaming \textbar{} Batch crawl 1 lần/ngày
  \textbar{} \textbar{} Kết luận \textbar{} Overkill \textbar{}
  \textbf{Phù hợp} \textbar{}
\item
  Tích hợp thành công luồng end-to-end:

  \begin{itemize}
  \tightlist
  \item
    Crawler crawl bài \(\rightarrow\) serialize JSON \(\rightarrow\)
    push SQS
  \item
    Lambda Consumer trigger từ SQS \(\rightarrow\) parse JSON
    \(\rightarrow\) SHA256 hash URL \(\rightarrow\) INSERT
    article\_metadata
  \item
    Deduplication hoạt động:
    \texttt{ON\ CONFLICT\ (url\_hash)\ DO\ NOTHING}
  \item
    Test 100 bài: 95 bài insert thành công, 5 bài trùng lặp bị bỏ qua
  \end{itemize}
\item
  Hiểu được Star Schema warehouse:

  \begin{itemize}
  \tightlist
  \item
    \textbf{Dimension tables}: \texttt{dim\_source} (nguồn báo),
    \texttt{dim\_time} (ngày tháng), \texttt{dim\_author} (tác giả),
    \texttt{dim\_content} (nội dung gốc)
  \item
    \textbf{Fact tables}: \texttt{fact\_articles} (bài viết),
    \texttt{fact\_chunks} (chunks sau khi cắt),
    \texttt{fact\_article\_authors} (M:N)
  \item
    Indexes: HNSW cho vector search, B-tree cho url\_hash, domain, date
  \end{itemize}
\end{itemize}
