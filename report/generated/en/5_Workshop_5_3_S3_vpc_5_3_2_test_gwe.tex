  several \textbf{EC2 instances}. \textbf{Session Manager} is a fully

  manage your \textbf{Amazon EC2 instances} and on-premises virtual

\hypertarget{section-summary}{%
\paragraph{Section summary}}

Congratulation on completing access to S3 from VPC. In this section, you
created a Gateway endpoint for Amazon S3, and used the AWS CLI to upload
an object. The upload worked because the Gateway endpoint allowed
communication to S3, without needing an Internet Gateway attached to
``VPC Cloud''. This demonstrates the functionality of the Gateway
endpoint as a secure path to S3 without traversing the Public Internet.
