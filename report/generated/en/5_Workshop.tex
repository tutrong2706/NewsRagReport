\section{News RAG Pipeline on AWS ---
Workshop}}

\hypertarget{project-introduction}{%
\subsection{Project Introduction}}

\textbf{News RAG Pipeline on AWS} is a complete end-to-end system that
automatically collects news articles from Vietnamese news sites,
processes them through a Data Warehouse (Star Schema), generates vector
embeddings using Amazon Bedrock, and provides an intelligent Q\&A
interface using Retrieval-Augmented Generation (RAG) architecture ---
all running serverless on AWS.

\hypertarget{architecture-overview}{%
\subsection{Architecture Overview}}

\hypertarget{local-development-v1---docker-compose}{%
\subsubsection{Local Development (v1 - Docker
Compose)}}

\begin{verbatim}
Scrapy Crawler $\rightarrow$ Kafka $\rightarrow$ PostgreSQL $\rightarrow$ ETL (Star Schema) $\rightarrow$ SentenceTransformer $\rightarrow$ Qdrant $\rightarrow$ RAG API
\end{verbatim}

\hypertarget{aws-serverless-production-v2---current}{%
\subsubsection{AWS Serverless Production (v2 -
Current)}}

\begin{verbatim}
EventBridge Scheduler (01:00, 02:00 UTC)
       |
       |---> Fargate Crawler (SitemapSpider) --> SQS --> Lambda Consumer --> Aurora PostgreSQL
       |
       `---> Lambda ETL + Embedding (Bedrock Titan) --> Aurora pgvector (HNSW Index)
                           |
                           v
                    Lambda RAG API <-- API Gateway <-- Client
                    (Bedrock embed query $\rightarrow$ pgvector search $\rightarrow$ Groq/Gemini LLM)
\end{verbatim}

\hypertarget{learning-objectives}{%
\subsection{Learning Objectives}}

By the end of this workshop, you will be able to:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Infrastructure as Code}: Define AWS infrastructure using
  Terraform (VPC, Aurora, ECS, Lambda, EventBridge)
\item
  \textbf{Serverless Containers}: Package and deploy Scrapy crawlers on
  ECS Fargate with ECR
\item
  \textbf{Data Warehouse Design}: Implement Star Schema in Aurora
  PostgreSQL with pgvector extension
\item
  \textbf{Workflow Automation}: Schedule daily pipelines using
  EventBridge Scheduler
\item
  \textbf{RAG System}: Integrate vector database (pgvector) with LLM
  APIs for intelligent Q\&A
\item
  \textbf{Cost Optimization}: Leverage serverless services to minimize
  operational costs (\textasciitilde\$21-26/month)
\end{enumerate}

\hypertarget{prerequisites}{%
\subsection{Prerequisites}}

\begin{itemize}
\tightlist
\item
  \textbf{AWS Account} with permissions for: VPC, EC2, RDS, ECS, ECR,
  Lambda, SQS, EventBridge, API Gateway, Bedrock, CloudWatch, IAM
\item
  \textbf{AWS CLI} configured (\texttt{aws\ configure})
\item
  \textbf{Terraform} \textgreater= 1.5.0
\item
  \textbf{Docker} \& \textbf{Docker Compose}
\item
  \textbf{Python} 3.10+
\item
  \textbf{Git}
\item
  \textbf{External APIs}: Groq API Key, Google Gemini API Key
\item
  \textbf{Bedrock Model Access}: Enable
  \texttt{amazon.titan-embed-text-v2:0} in AWS Console
\end{itemize}
