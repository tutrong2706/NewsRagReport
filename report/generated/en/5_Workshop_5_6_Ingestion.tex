\hypertarget{aws-lambda-version-production}{%
\subsection{AWS Lambda Version
(Production)}}

For AWS deployment, the consumer runs as a Lambda function triggered by
SQS (not Kafka directly). See \href{5.11-Lambda-Consumer/}{Lambda
Consumer} for the SQS \(\rightarrow\) Lambda \(\rightarrow\) Aurora
implementation.

Key differences: - \textbf{Trigger}: SQS queue (not Kafka) -
\textbf{Runtime}: Python 3.11 Lambda (15 min timeout) -
\textbf{Database}: Aurora PostgreSQL (not local) - \textbf{Secrets}:
Retrieved from AWS Secrets Manager - \textbf{Batching}: Processes up to
10 messages per invocation
