\section{AWS Deployment Preparation}}

This section covers building Docker images, pushing to ECR, and
preparing Lambda deployment packages for the AWS serverless
architecture.

\hypertarget{prerequisites}{%
\subsection{Prerequisites}}

\begin{itemize}
\tightlist
\item
  Terraform infrastructure deployed (see
  \href{5.3-Infrastructure/}{Infrastructure})
\item
  AWS CLI configured with appropriate permissions
\item
  Docker installed and running
\end{itemize}

\subsection{Lambda Deployment Package}}

\hypertarget{directory-structure-for-lambda}{%
\subsubsection{Directory Structure for
Lambda}}

\begin{verbatim}
deploy/
|--- consumer/
|   |--- lambda_function.py
|   `--- requirements.txt
|--- etl/
|   |--- lambda_function.py
|   `--- requirements.txt
`--- rag-api/
    |--- lambda_function.py
    `--- requirements.txt
\end{verbatim}
