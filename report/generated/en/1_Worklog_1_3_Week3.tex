\hypertarget{week-3-results}{%
\subsubsection{Week 3 Results:}}

\begin{itemize}
\tightlist
\item
  Completed \texttt{NewsRAGSpider} (\texttt{crawler/spiders/spider.py})
  with features:

  \begin{itemize}
  \tightlist
  \item
    \textbf{parse()}: Traverses all links on page, filters same-domain
    URLs, classifies articles vs category pages
  \item
    \textbf{parse\_article()}: Uses \texttt{newspaper3k} combined with
    CSS Selectors
  \item
    \textbf{Custom settings}: CONCURRENT\_REQUESTS=16 (Windows) / 32
    (Linux), DOWNLOAD\_DELAY=1.0/0.5, DEPTH\_LIMIT=5
  \end{itemize}
\item
  Built complex author extraction system with multi-level fallback:

  \begin{enumerate}
  \def\labelenumi{\arabic{enumi}.}
  \tightlist
  \item
    Extract from \texttt{newspaper3k} \(\rightarrow\) validate
  \item
    Fallback through 12+ CSS selectors: \texttt{.author-name},
    \texttt{.tac-gia}, \texttt{a{[}href*="tac-gia"{]}},\ldots{}
  \item
    Scan bottom paragraphs for patterns like ``Theo: \ldots{}'' /
    ``Nguon: \ldots{}''
  \item
    Final fallback to \texttt{meta{[}name="author"{]}}
  \end{enumerate}

  \begin{itemize}
  \tightlist
  \item
    \texttt{is\_valid\_author()} checks: length 2-100 chars, no
    URLs/emails, no date patterns, no bad words (newspaper names,
    generic labels)
  \end{itemize}
\item
  Handled diverse date parsing:

  \begin{itemize}
  \tightlist
  \item
    ISO format: \texttt{2026-07-01T14:30:00}
  \item
    VN format: \texttt{17/06/2026\ 14:30} or \texttt{01-07-2026}
  \item
    Fallback through 10 CSS selectors + \texttt{article.publish\_date}
  \item
    Standardized output: \texttt{YYYY-MM-DD\ HH:MM:SS}
  \end{itemize}
\item
  Completed \texttt{KafkaPipeline} (\texttt{crawler/pipelines.py}):

  \begin{itemize}
  \tightlist
  \item
    Serializes item to JSON (ensure\_ascii=False for Vietnamese)
  \item
    Pushes to Kafka topic \texttt{news\_raw}
  \item
    Producer flush after each item
  \end{itemize}
\item
  Successfully tested local crawling with valid output format
\end{itemize}
