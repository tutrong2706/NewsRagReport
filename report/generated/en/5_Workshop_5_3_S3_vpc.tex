\paragraph{Building Automated Crawler with Scrapy and ECS
Fargate}}

The Crawler module is responsible for collecting new articles daily and
pushing them to the SQS queue for processing. Using ECS Fargate
eliminates the 15-minute timeout limit of AWS Lambda (v1 architecture).

\textbf{1. Scrapy SitemapSpider}

Unlike CrawlSpider which relies on links from the homepage,
SitemapSpider directly reads the \texttt{sitemap\_news.xml} file of
newspapers to ensure no older articles are missed.
