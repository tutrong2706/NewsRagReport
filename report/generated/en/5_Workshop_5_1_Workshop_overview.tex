\section{News RAG Pipeline on AWS --- Workshop
Overview}}

This workshop guides you through building a complete \textbf{News RAG
(Retrieval-Augmented Generation) Pipeline} on AWS using serverless
architecture. You will learn to design, deploy, and operate an
end-to-end system that automatically crawls news articles, processes
them into a Data Warehouse, generates vector embeddings, and enables
intelligent Q\&A using LLMs.

\hypertarget{learning-objectives}{%
\subsection{Learning Objectives}}

By the end of this workshop, you will be able to:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Infrastructure as Code}: Define AWS infrastructure using
  Terraform (VPC, Aurora, ECS, Lambda, EventBridge)
\item
  \textbf{Serverless Containers}: Package and deploy Scrapy crawlers on
  ECS Fargate with ECR
\item
  \textbf{Data Warehouse Design}: Implement Star Schema in Aurora
  PostgreSQL with pgvector extension
\item
  \textbf{Workflow Automation}: Schedule daily pipelines using
  EventBridge Scheduler
\item
  \textbf{RAG System}: Build retrieval-augmented generation with Bedrock
  embeddings and external LLMs
\item
  \textbf{Cost Optimization}: Leverage serverless services to minimize
  operational costs (\textasciitilde\$21-26/month)
\end{enumerate}

\hypertarget{prerequisites}{%
\subsection{Prerequisites}}

\begin{itemize}
\tightlist
\item
  \textbf{AWS Account} with permissions for: VPC, EC2, RDS, ECS, ECR,
  Lambda, SQS, EventBridge, API Gateway, Bedrock, CloudWatch, IAM
\item
  \textbf{AWS CLI} configured (\texttt{aws\ configure}) with appropriate
  credentials
\item
  \textbf{Terraform} \textgreater= 1.5.0 installed
\item
  \textbf{Docker} \& \textbf{Docker Compose} installed
\item
  \textbf{Python} 3.10+ with pip
\item
  \textbf{Git} for version control
\item
  \textbf{Code Editor} (VS Code recommended)
\end{itemize}
