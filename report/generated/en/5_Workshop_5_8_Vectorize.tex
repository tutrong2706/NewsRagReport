\hypertarget{aws-production-etl-embedding-merged}{%
\subsection{AWS Production: ETL + Embedding
Merged}}

In the AWS deployment, the vectorize step is \textbf{not separate}. The
Lambda ETL function: 1. Fetches unprocessed articles 2. Cleans HTML,
chunks text (\textasciitilde500 tokens) 3. Calls
\texttt{bedrock.invoke\_model} for each chunk 4. Inserts directly into
\texttt{fact\_chunks.embedding} (pgvector)

See \href{5.12-Lambda-ETL/}{Lambda ETL + Embedding} for the production
implementation.
