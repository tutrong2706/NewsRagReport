\hypertarget{week-2-results}{%
\subsubsection{Week 2 Results:}}

\begin{itemize}
\tightlist
\item
  Mastered Scrapy project structure:

  \begin{itemize}
  \tightlist
  \item
    \texttt{spiders/}: contains spider classes
  \item
    \texttt{pipelines.py}: processes items after spider yields
  \item
    \texttt{settings.py}: configures CONCURRENT\_REQUESTS,
    DOWNLOAD\_DELAY, DEPTH\_LIMIT,\ldots{}
  \end{itemize}
\item
  Understood the key differences between 2 spider types:

  \begin{itemize}
  \tightlist
  \item
    \textbf{CrawlSpider (v1)}: Uses \texttt{DEPTH\_LIMIT=5}, only crawls
    pages within link scope \(\rightarrow\) misses old articles not
    linked from homepage
  \item
    \textbf{SitemapSpider (v2)}: Reads directly from sitemap XML file
    \(\rightarrow\) crawls all articles including old ones, avoids
    Lambda's 15-minute timeout
  \end{itemize}
\item
  Analyzed sitemap XML of 3 news outlets:

  \begin{itemize}
  \tightlist
  \item
    VnExpress: \texttt{https://vnexpress.net/sitemap\_news.xml}
  \item
    Thanh Niên: \texttt{https://thanhnien.vn/sitemap.xml}
  \item
    VietnamNet: \texttt{https://vietnamnet.vn/sitemap\_news.xml}
  \end{itemize}
\item
  Acquired necessary Docker knowledge:

  \begin{itemize}
  \tightlist
  \item
    How to write optimized Dockerfile (base image
    \texttt{python:3.10-slim}, multi-layer caching)
  \item
    Docker Compose to run PostgreSQL + Kafka locally
  \item
    Understanding \texttt{.env} files and how to inject into containers
  \end{itemize}
\item
  Studied \texttt{newspaper3k}:

  \begin{itemize}
  \tightlist
  \item
    Python library for extracting title, content, author, publish\_date
    from HTML
  \item
    Uses \texttt{article.set\_html()} + \texttt{article.parse()} instead
    of direct download
  \item
    Combined with Scrapy's CSS Selectors for improved accuracy
  \end{itemize}
\end{itemize}
