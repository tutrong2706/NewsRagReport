Throughout my internship at the \textbf{First Cloud AI Journey} program
(AWS Vietnam) from \textbf{June 15, 2025} to \textbf{August 14, 2025}, I
had the opportunity to learn, practice, and apply my knowledge in a real
working environment.

I participated in developing the \textbf{Crawl + Queue} module for the
\textbf{NewsRAG} project --- an intelligent news aggregation and
analysis system on AWS. Through this experience, I improved my skills in
Python programming, web scraping, Docker containerization, AWS services
(ECS Fargate, SQS, ECR, EventBridge), and Infrastructure as Code
(Terraform).

In terms of work ethic, I always strived to complete assigned tasks
well, proactively researched new technologies, and actively coordinated
with team members to ensure smooth system integration.

To objectively reflect on my internship, I self-assess based on the
following criteria:
