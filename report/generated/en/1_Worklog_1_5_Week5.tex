\hypertarget{week-5-results}{%
\subsubsection{Week 5 Results:}}

\begin{itemize}
\item
  Successfully configured SQS:

  \begin{itemize}
  \tightlist
  \item
    \textbf{SQS Standard Queue}: \texttt{newsrag-articles} --- cost
    \textasciitilde\$0/month (vs Kafka requiring management overhead)
  \item
    \textbf{Dead Letter Queue}: \texttt{newsrag-articles-dlq} ---
    catches failed messages after 3 retries
  \item
    Message retention: 4 days, visibility timeout: 30 seconds
  \end{itemize}
\item
  Clear understanding of Kafka \(\rightarrow\) SQS migration rationale:
  \textbar{} Criteria \textbar{} Kafka (v1) \textbar{} SQS (v2)
  \textbar{}
  \textbar-----------------\textbar----------------------\textbar------------------------\textbar{}
  \textbar{} Cost \textbar{} Container overhead \textbar{}
  \textasciitilde\$0/month \textbar{} \textbar{} Management \textbar{}
  Maintain broker \textbar{} Fully managed \textbar{} \textbar{} Use
  case \textbar{} Real-time streaming \textbar{} Daily batch crawl
  \textbar{} \textbar{} Conclusion \textbar{} Overkill \textbar{}
  \textbf{Best fit} \textbar{}
\item
  Successfully integrated end-to-end flow:

  \begin{itemize}
  \tightlist
  \item
    Crawler crawls articles \(\rightarrow\) serializes JSON
    \(\rightarrow\) pushes to SQS
  \item
    Lambda Consumer triggered by SQS \(\rightarrow\) parses JSON
    \(\rightarrow\) SHA256 hashes URL \(\rightarrow\) INSERTs
    article\_metadata
  \item
    Deduplication works: \texttt{ON\ CONFLICT\ (url\_hash)\ DO\ NOTHING}
  \item
    Test with 100 articles: 95 successfully inserted, 5 duplicates
    skipped
  \end{itemize}
\item
  Understood Star Schema warehouse design:

  \begin{itemize}
  \tightlist
  \item
    \textbf{Dimension tables}: \texttt{dim\_source} (news source),
    \texttt{dim\_time} (date), \texttt{dim\_author} (author),
    \texttt{dim\_content} (raw content)
  \item
    \textbf{Fact tables}: \texttt{fact\_articles} (articles),
    \texttt{fact\_chunks} (chunks after splitting),
    \texttt{fact\_article\_authors} (M:N)
  \item
    Indexes: HNSW for vector search, B-tree for url\_hash, domain, date
  \end{itemize}
\end{itemize}
