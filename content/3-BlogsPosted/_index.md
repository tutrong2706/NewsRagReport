During my internship, I prepared 3 blog posts for [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj), sharing knowledge and experience from the NewsRAG project:

###  [Blog 1 - BUILDING AN AUTOMATED NEWS CRAWLING SYSTEM WITH SCRAPY ON AWS ECS FARGATE](3.1-Blog1/)
This blog shares the experience of building an automated news crawling system from 3 Vietnamese newspapers (VnExpress, Thanh Niên, VietnamNet) using Scrapy framework, packaging Docker containers and deploying on AWS ECS Fargate. Includes real-world challenges encountered when extracting Vietnamese article information.

###  [Blog 2 - COMPARING KAFKA AND AMAZON SQS: WHEN TO USE WHICH?](3.2-Blog2/)
A detailed analysis of the differences between Apache Kafka and Amazon SQS, based on real experience transitioning from Kafka to SQS in the NewsRAG project. Helps readers understand when to use a simple message queue instead of an event streaming platform.

###  [Blog 3 - DEPLOYING INFRASTRUCTURE AS CODE WITH TERRAFORM FOR AWS PROJECTS](3.3-Blog3/)
A guide on using Terraform to manage entire AWS infrastructure (VPC, RDS, ECS, EventBridge) for a real project. Shares best practices on organizing Terraform config, managing sensitive variables, and automating deployment.
